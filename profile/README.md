## How DBF Viewer 2000 Sits

DBF Viewer 2000 does not replace the printer or the folder that already holds your DBF. It sits beside them as a named table viewer for rows and memo fields on a file you own.

If two people share a PC, each keeps a DBF Viewer 2000 file desk of their own. Extra files wait for their own title instead of crowding the live view.

A first visit should be one short table, then the same DBF Viewer 2000 table viewer the next day. That is enough to see if the layout holds.

## Open Order

1. Open the last DBF Viewer 2000 session on a DBF you own, not a new empty viewer.
2. Read the table viewer, the memo fields, and the last handoff.
3. Finish one visible read or DBF Viewer 2000 DBF print on your own rows.
4. Write what you printed, then close with fewer loose views than you found.
5. If the file desk feels crowded, drop anything that belongs to a different DBF.
6. Leave memo fields on the same named DBF Viewer 2000 file desk.

## After a Week

A week in DBF Viewer 2000 is not more open views. It is the same table viewer, a shorter row set, and a note that still makes sense on Monday. If every DBF is pinned, nothing stands out.

Other programs stay where they are. DBF Viewer 2000 only keeps the path back: file name, rows, memo fields, print, handoff.
Leave the file desk with a quieter print list than the one you opened.
